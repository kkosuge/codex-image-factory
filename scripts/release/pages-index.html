Codex Image Factory

Codex CLI（ChatGPT のサブスクリプション）をエンジンにして、画像アセットをキューで続けて生成する macOS アプリ。

最新版をダウンロード

macOS 15 以降。Codex CLI をインストールし、codex login でログインしておいてください。

アップデートはアプリが自動で確認し、終了したときに入れ替えます。

OpenAI の公式アプリではありません。Codex は OpenAI の商標です。
